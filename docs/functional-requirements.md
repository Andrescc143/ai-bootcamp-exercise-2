# Functional Requirements

This TODO application manages a simple list of tasks stored through the `/api/items` endpoints.

1. The user can view the current task list when the app loads.
2. The user can add a new task by entering a non-empty name and submitting the form.
3. The user can delete an existing task from the list.
4. The app shows loading, empty, and error states while reading or updating tasks.
5. The task list is displayed with the most recently created items first.
6. The user can edit the task.
7. A task can have 3 different states: Defined, Started, Completed.
