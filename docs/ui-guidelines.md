# UI Guidelines

These guidelines define the visual direction for the TODO app.

1. Use the Colombia flag colors as the core palette: yellow, blue, and red. Favor muted or deep tones for surfaces, and reserve bright yellow for emphasis.
2. Keep the interface minimal and modern, with generous whitespace, clean alignment, and simple card-based layouts.
3. Use a bold, heavy-metal-inspired display font for headings and key labels, paired with a highly readable sans-serif for body text and controls. Do not copy a branded font verbatim.
4. Maintain strong visual hierarchy through size, weight, spacing, and color contrast so the primary action is always obvious.
5. Ensure every interactive element has an accessible name, clear label, and visible focus state.
6. All text and controls must meet accessible color-contrast standards, including hover, disabled, error, and selected states.
7. Use consistent spacing, border radius, and subtle shadows to create a cohesive and calm interface.
8. Design for responsive behavior so the app remains clear and usable on mobile, tablet, and desktop.
